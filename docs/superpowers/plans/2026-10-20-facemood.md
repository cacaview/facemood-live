# FaceMood Live Implementation Plan
> For agentic workers: execute inline using superpowers:executing-plans. User authorized autonomous implementation; no additional design approval gate.

**Goal:** Real local browser face-expression inference with reproducible audit, baseline, tests and bounded training tools.
**Architecture:** A single-flight worker performs MediaPipe detection and ORT WASM classification, Vue renders results and metrics. Python reads immutable zip for audits/evaluation/training.
**Tech Stack:** Vue 3, TypeScript, Vite, Vitest, Playwright, ORT Web, MediaPipe, Python/PyTorch.
**Spec:** docs/superpowers/specs/2026-10-20-facemood-design.md

## Global Constraints
- No GPU usage/service changes/publication without explicit authorization.
- No original image modification, frame uploads, audio or automatic screenshots.
- Largest face only; no predictions when no face; no stale queue; WASM default.
- PrivateTest not used for tuning; manual device results never inferred from simulation.
- Runtime assets local, pinned dependencies, licenses recorded.

## Review Focus
- Permission denial and camera request resolving after stop: stop tracks and allow recovery.
- Worker errors and late results: clear busy and stale predictions, restart cleanly.
- Empty/invalid/no-face media: explanatory states, never random classification.
- Interrupted offline installation: don't claim ready until all model/runtime files are cached.
- GPU budget timeout/OOM/signal: checkpoint and failure records; do not assert service resumed.

## Tasks
- [x] 1. Audit: scripts/audit_dataset.py -> reports/dataset_audit.md, dataset_manifest.csv, class_distribution.csv, duplicates.csv. Tests synthetic zip corruption, labels, duplicate leakage; run pytest red then green.
- [x] 2. Freeze baseline: scripts/fetch_assets.mjs plus scripts/evaluate.py -> models/baseline manifest, SHA256, CPU fixture and PublicTest fixed evaluation. Compare raw probabilities, never smoothed.
- [x] 3. Inference core: src/core.ts defines crop, grayscale, stable softmax, low confidence, rolling metrics; tests boundaries/NaNs/no-face/window and run Vitest red then green.
- [x] 4. Browser: src/inference.worker.ts protocol init/frame/result/error, src/engine.ts serialized lifecycle, src/App.vue camera + media + metrics. Build and Playwright real model smoke, denied camera recovery and offline checks.
- [x] 5. Training: training/train.py, telemetry.py, export.py. CPU smoke, budget math, atomic checkpoint/resume, export numerical comparison. GPU never run here.
- [x] 6. Delivery: README, model_card, privacy, licenses, reports/test_report.md, gpu reports, manual device matrix, local preview and production build; inspect final changes and fix important issues.

Local tooling/tasks checked. Target-device acceptance, GPU experiments and external publication remain pending as documented; these checkboxes do not imply full PRD acceptance.
