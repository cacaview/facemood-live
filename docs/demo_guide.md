# 决赛演示顺序

1. 提前在比赛同一设备/同一浏览器/HTTPS打开页面，保持网络可用，等待页面完成版本检查、必要下载并显示模型就绪；点击「内置样例」确保实际识别。保留已验收的构建备份。
2. 首先说明“识别可见面部表情，不能读取真实内心情绪”。点击「启动摄像头」，授权 video；确认脸框和真实分类FPS有更新。主脸应正对摄像头、光线均匀、距离适中。
3. 改变表情，展示概率、低信度状态与统计；移出画面，确认不再输出分类。多人时说明只分析最大主脸。
4. 无摄像头/权限被拒时使用内置 NASA 公开领域样例或已获同意的本地图片、MP4；页面有“演示素材”标签，不能称作实时画面。
5. 导出统计不含图像。截图会包含人脸，先取得同意，再确认弹窗导出。
6. 需要联网打开页面并检查模型版本；已有模型会复用本地存储，更新/损坏时重新下载，不提供整站离线入口。iPhone必须HTTPS/受信任证书，局域网HTTP只能测试素材UI，不能保证摄像头。
7. 点击停止结束采集；后台会自动停止并要求重新启动。模型出错点「加载/重试」，不要现场更换未经验证模型。
