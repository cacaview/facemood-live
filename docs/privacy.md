# 隐私说明
画面仅在本设备浏览器的内存中处理。摄像头只请求 video，不请求音频。没有账户、分析埋点、云 API、视频上传或跨设备同步。启动后只访问本网站本地路径获取静态文件、WASM、模型和演示样例；浏览器IndexedDB仅保存模型文件及版本摘要，不保存用户图片、视频或摄像头画面。页面打开会请求最新模型配置；更新时从同一网站下载权重，无画面上传。旧整站离线缓存迁移时会被清理。

推理只分析最大人脸，不识别身份。最近60秒统计临时保存在内存，刷新清除。JSON统计可由用户主动导出，包含概率和耗时，不包含面部图像。截图会在确认后包含人脸并下载到设备。用户应取得画面中其他人的同意。停止或进入后台后停止摄像头轨道。

表情不是内心情绪、医学或心理诊断。概率未经过人群校准，显示低置信度不能用来判断人群属性或心理状态。网站HTTPS托管服务会接收正常静态资源请求元信息，但应用不发送用户人脸画面。
